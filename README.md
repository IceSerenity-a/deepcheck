# deepcheck.

A simple website that helps you learn how to spot deepfakes.
Deepfakes are photos, videos or audio made or changed using AI.

## How to open the website

1. Extract the website ZIP file.
2. Open the `deepcheck` folder.
3. Double-click `index.html` to open it in your browser.

Keep all the files and the `media` folder together. You do not need to install anything.

## Features

- **Home:** Read a short explanation about deepfakes.
- **Scenario quiz:** Answer questions about visual clues, audio, videos and checking sources.
- **Spot a deepfake:** Guess whether each photo or GIF sample is real or fake.
- **Practice mode:** Answer without a time limit.
- **Timed mode:** You have 30 seconds for each question.
- **Review:** See your missed answers and read the explanations.

## Main files

- `index.html` — the pages and content.
- `styles.css` — the colours, layout and design.
- `app.js` — the quizzes, timer and scoring.
- `media/` — the photos and GIF samples.

## GIF note

The supplied GIF files contain still images. To make them move, replace them with the original animated GIFs. Keep the same filenames.

## Reminder

This is a learning quiz, not an automatic deepfake detector. The media answers follow the real/fake labels supplied with the files.
